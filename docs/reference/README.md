# Material de referencia

Coloca aquí el material fuente del proyecto:

- `teoria-matriz-rigidez.pdf` — documento del profesor (teoría, ecuaciones, código MATLAB).
- `ui-*.png` — capturas de la interfaz original a replicar/mejorar.
- `caso-*.md` — casos de validación numérica extraídos del PDF (entrada + resultado esperado).

Los casos de validación se traducen a tests en `tests/truss/`.
